Noiseless (`noise_model=SDEM3_p=0.0`), Z-basis memory circuits copied from
https://github.com/oscarhiggott/hyperbolic-floquet-data (Apache-2.0, see `LICENSE`), for the paper
"Constructions and performance of hyperbolic and semi-hyperbolic Floquet codes",
O. Higgott and N. P. Breuckmann, arXiv:2308.03750.

Filenames give the seed tiling, the number of data qubits `n`, logical qubits `k` and embedded distance `d`.
These are the purely hyperbolic (`l=1`) codes with `d >= 3` and at most 240 data qubits.
